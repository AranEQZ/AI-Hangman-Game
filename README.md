# AI Hangman Game

This is a **simple Hangman game** made in Python for a university AI project.  
It uses **AI concepts** to help the player guess letters more intelligently.

---

## Features

- **3 Difficulty Levels:** Easy, Medium, Hard  
- **AI Hint System:** Suggests letters based on frequency  
- **Win/Lose Logic:** Tracks correct and wrong guesses  
- **Console-Based Game:** Easy to run without extra libraries  

---

## How to Play

1. Run the game in Python: `python hangman_ai.py`  
2. Choose a difficulty level.  
3. Guess letters to reveal the word.  
4. Use the AI hint if you get stuck.  
5. Try to guess the word before the hangman is complete!  

---

## AI Concepts Used

- **Knowledge Base:** Word lists by difficulty  
- **Heuristic Reasoning:** AI chooses letters intelligently  
- **Decision Making:** AI selects a word based on difficulty  
- **User Interaction:** Shows guessed letters and progress
